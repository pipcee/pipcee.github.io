Bring`s Blog — 新生训练环境配置清单 2026.1

[ ] 安装 C++17 编译器（g++ 或 clang++）
[ ] 安装 Python 3.11+
[ ] 安装 Git，并配置 user.name / user.email
[ ] 安装 VS Code 或 CLion
[ ] 安装浏览器，收藏 OI Wiki 与 Codeforces
[ ] 建立 ~/cp 目录，放入 template.cpp
[ ] 配置一键编译命令：g++ -std=c++17 -O2 -Wall
[ ] 用 hello world 验证编译、运行、重定向输入输出
[ ] 学会使用 diff 对拍两个程序
[ ] 创建一个私有 Git 仓库保存训练代码
[ ] 配置编辑器格式化与保存时自动编译（可选）
[ ] 注册 OJ 账号，完成注册后的第一道 A+B
[ ] 记录常用命令到自己的速查表

每日训练建议
1. 先读题，复述输入输出与数据范围。
2. 想清楚暴力解法，再找优化方向。
3. 代码写完后，手动构造一组边界数据。
4. 提交后，无论 AC 与否都写一句复盘。

安全与协作
- 不把密码写入代码或公开仓库。
- 使用学校提供的 Wi-Fi 时，优先访问 HTTPS。
- 借用机房设备时，离开前退出个人账号。
- 遇到无法解决的问题，先记录复现步骤再提问。
