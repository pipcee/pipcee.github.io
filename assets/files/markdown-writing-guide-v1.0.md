# Markdown 写作约定 · v1.0

## 标题

- 一级标题只用于文章标题。
- 正文最深到三级标题。
- 同级标题语义一致，不跳级。
- 标题末尾不加句号。

## 段落

- 每段尽量不超过四行。
- 重要结论放在段首。
- 一段只表达一个中心意思。
- 中文与英文之间留一个空格。

## 代码

始终标注语言：

    ```cpp
    int main() { return 0; }
    ```

代码块上方说明意图，下方说明结果。命令行与代码分开标注。

## 链接与引用

- 链接文字应能独立说明去向，避免“点这里”。
- 引用用于他人观点或需要强调的结论，不用于自我强调。
- 图片必须有替代文本。

## 列表

- 并列内容用无序列表。
- 步骤用有序列表。
- 嵌套最多两层。
- 不把整篇文章都写成列表。

## 发布前检查

- [ ] 标题与文件名一致
- [ ] 每个代码块都有语言标签
- [ ] 没有失效链接
- [ ] 移动端预览不少于一次
- [ ] 放一天后重读，删掉不必要的句子
