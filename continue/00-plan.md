# 00 · 项目计划与验收矩阵

> 项目：Bring`s Blog 静态博客效果示例  
> 技术约束：纯 HTML / CSS / JavaScript，零运行时外部依赖，不接入真实后端。  
> 记录规则：每个模块完成后在本目录新增一份 `xx-模块名.md`，记录变更、验证方式与后端预留接口。

## 1. 目标

构建一套白色、简介风格的博客网页示例，共五个核心页面：

| 页面 | 文件 | 核心内容 |
| --- | --- | --- |
| 首页 | `index.html` | Bring`s Blog 品牌标题、四个一行导航、25 只鸟的 2D 群集动画 |
| 个人介绍 | `about.html` | 头像、大二状态、个人简介、圆角矩形奖项 |
| 文章 | `articles.html` → `notes.html` → `note.html` | 四个文件夹、分页笔记列表、笔记详情 |
| 图库 | `gallery.html` | 每行三个文件夹、封面图、灯箱图片展示 |
| 资源 | `resources.html` | 下载列表、MD5、URL 按钮、下载按钮、版本、分页 |

## 2. 视觉方向

- 大面积纯白背景，暖灰辅助面，近黑正文；不使用高饱和主色。
- 标题采用衬线字，正文采用系统中文字体；代码与序号使用等宽字。
- 圆角矩形用于奖项、图库文件夹、资源下载卡片；细描边 + 轻阴影。
- 首页品牌位于上方中部，四个导航按钮保持同一行。
- 动效克制：淡入、悬停微位移、鸟群持续游动；支持 `prefers-reduced-motion`。
- 零外部字体、零框架、零图标库；图标全部使用内联 SVG 或系统字符。

### 数据与接口边界

- 页面不直接散落业务数据，统一调用 `window.BlogAPI`。
- `data.js` 仅作为 Mock 数据源；`api.js` 内通过 `BLOG_API_CONFIG.useMock` 在 Mock / 真实 HTTP 间切换。
- 真实后端统一约定 `GET /api/...` JSON；资源下载使用后端返回的临时/签名地址。
- 所有后端能力在代码中用 `[后端预留]` 标注，并在 `continue/08-backend-api.md` 汇总。
- 分页响应统一为 `{ items, page, pageSize, total, totalPages }`。

## 4. 首页鸟群算法验收

- 数量固定为 **25**。
- 使用 2D 平面 Boids：分离、对齐、聚合 + 鼠标排斥 + 轻微游荡。
- 屏幕上下、左右均环绕联通（模拟环面，邻域距离也使用环绕最短距离）。
- 鼠标靠近时鸟群散开，移开后恢复聚集。
- Canvas 固定铺满视口，`z-index: 0`；品牌与导航图层位于其上。
- 单只鸟用**凹四边形**绘制，鸟身中线加粗，整体保持倒 V 箭头意象。
- 窗口尺寸变化时重新计算边界，不产生鸟数量变化。
