# 01 · 基础工程与全局设计系统

## 本步提交内容

- 初始化纯静态博客目录结构：`css/`、`js/`、`assets/`、`continue/`。
- 新增全局样式 `css/style.css`：
  - 白色、暖灰、近黑的设计变量；
  - 系统中文字体 + 衬线标题 + 等宽标注，零外部字体；
  - 页面容器（1180px）、顶部导航、页脚、页面标题、按钮、标签、分页；
  - 载入/空/错误状态；
  - 首页、个人介绍基础版式的共享部分；
  - 移动端导航与断点规则。
- 新增 `js/common.js`：
  - 根据 `body[data-page]` 自动标记顶部导航的 `aria-current`；
  - 移动端菜单开合、Esc 关闭、点击外部关闭；
  - 页脚年份自动更新；
  - `[data-reveal]` 的滚动淡入（尊重 `prefers-reduced-motion`）；
  - 通用工具：`escapeHTML`、`formatDate`、query 读取、分页 DOM 生成。
- 新增站点图标 `assets/favicon.svg`。

## 设计系统

| Token | 值 | 用途 |
| --- | --- | --- |
| `--paper` | `#ffffff` | 主背景 |
| `--paper-soft` | `#f7f7f3` | 轻卡片 / 标签 |
| `--ink` | `#1a1a17` | 正文与按钮 |
| `--ink-soft` | `#56574f` | 次级正文 |
| `--ink-muted` | `#8a8b82` | 注释、元信息 |
| `--line` | `#e7e6df` | 细描边 |
| `--accent` | `#34584b` | 极少量绿色点缀 |
| `--radius-xl` | `28px` | 大圆角矩形 |
| `--container` | `1180px` | 主内容宽度 |

- 不加载外部字体、CSS 框架、JS 框架或图标库。
- 图标全部使用内联 SVG；品牌字中的 `` ` `` 按用户文案保留。
- 响应式断点：`900px / 760px / 720px / 520px`。

## 后端功能与预留

本步骤本身**不含任何后端逻辑**，导航和页脚为静态 HTML。

| 标记 | 说明 |
| --- | --- |
| `[后端预留] GET /api/site` | 若站点名、简介、社交链接需要后台配置，可由该接口返回；当前使用静态 HTML 与 `BLOG_DATA.site`。 |
| — | 移动菜单、年份、滚动淡入均为纯前端行为，无后端接口。 |
