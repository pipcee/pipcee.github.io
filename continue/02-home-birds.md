# 02 · 首页与 25 只鸟的群集动画

## 本步提交内容

- 新增 `index.html`：
  - 顶部中部品牌标题 `Bring`s Blog`；
  - 四个同一行的导航按钮：个人介绍 / 文章 / 图库 / 资源；
  - 全屏背景 Canvas：`#bird-canvas`，`z-index: 0`，位于所有内容最下层；
  - 移动鼠标提示、页脚链接、跳转主内容链接。
- 新增 `js/home.js`：
  - 固定 **25** 只鸟；
  - 分离（separation）、对齐（alignment）、聚合（cohesion）；
  - 鼠标斥力，鼠标移出窗口后恢复；
  - 靠近指针时使用硬安全圈（46px）防止鸟在指针中心形成微小轨道；
  - 上下、左右环绕（环面拓扑），邻域距离也使用环绕最短距离；
  - 边界 resize 时按比例重排，鸟数量保持 25；
  - `prefers-reduced-motion` 时只绘制静态首帧，不启动动画循环，同时关闭首屏 CSS 动画。
- `css/style.css` 新增首页首屏、品牌字、四宫格导航及响应式样式。

## 鸟的绘制方式

每只鸟由 Canvas 2D 路径绘制为一个**凹四边形**：

```text
            朝向
          (11.4, 0)
           /      \
     (-8.2,-8)   (-8.2, 8)
           \      /
          (-3.3, 0)   ← 内凹点
```

- 4 个顶点构成凹四边形，外轮廓保留倒 V / 箭头意象；
- 再从内凹点向尖端画一条 `2.15px` 的加粗中线，满足“中间加粗”；
- 整体为近黑半透明填充，叠在白色背景的最底层，不干扰上层文字点击；
- Canvas 使用 `pointer-events: none`，`z-index: 0`，内容层 `.home-shell` 为 `z-index: 1`。

## 首页布局约束

- 品牌在页面上部正中央，`font-size: clamp(64px, 10.6vw, 134px)`。
- 四个导航按钮使用 `grid-template-columns: repeat(4, ...)`，任何断点均保持一行四列。
- 手机端（≤520px）收窄内边距、隐藏英文副标题，但仍保持四列。
- 导航按钮为大圆角、白底半透明卡片；悬浮时反转为黑底白字。

## 后端功能与预留

本页**不依赖后端**，鸟群计算和导航均在浏览器完成。

| 项目 | 状态 | 说明 |
| --- | --- | --- |
| 鸟群动画 | 纯前端 Canvas | 无接口 |
| 导航按钮 | 静态 HTML | 无接口 |
| 社交链接 | 静态示例 | 后续可由 `GET /api/site` 返回 |

## 验证计划

- 用诊断对象 `window.__birdFlock.count()` 检查数量必须为 25。
- 检查连续采样位置发生变化，确认动画在运行。
- 移动鼠标后检查鸟的速度方向发生改变。
- 检查 Canvas 的实际堆叠层级低于 `.home-shell`。
- 在 1440px、768px、390px 宽度做视觉检查，确认导航始终一行四个。

## 实际验证结果

- 25 只鸟全部初始化，60fps 下 20/25 只以上随机采样均有位移。
- 将鼠标放在某只鸟的位置后 950ms，该鸟远离指针 **> 18px**（最终约 153px）。
- Canvas `z-index: 0`，内容层 `.home-shell` `z-index: 1`，层级正确。
- 桌面与 390px 移动端四个导航按钮始终在同一行。

## 验证中修正

1. 鼠标避让向量最初写成了“指向鼠标”，会让鸟被吸引。已改为从鼠标指向鸟的向量。
2. 当鼠标恰好落在鸟身上时，极小的位移向量会让鸟围绕指针形成约 1px 的轨道；增加 46px 安全圈与确定性回退方向后，鸟会稳定逃离。
