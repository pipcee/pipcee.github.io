## 4. 可访问性检查

- 页面有 skip link、语义化 header/main/nav/footer 和单一 h1；
- 导航当前项通过 `aria-current="page"` 标记；
- 移动菜单有 `aria-expanded` 与 `aria-controls`；
- 图库灯箱使用 `role="dialog"`、`aria-modal`、`aria-labelledby`、`aria-describedby`；
- 灯箱包含焦点移入、`Tab` 循环、`Esc` 关闭与关闭后焦点恢复；
- 所有图片有 alt（装饰性 SVG 与图标有 `aria-hidden`）；
- 全部交互可用键盘操作，`:focus-visible` 有清晰轮廓；
- 色彩对比以近黑正文 + 白底为主，注释类小字使用次级灰色；
- 开启减少动态效果后，CSS 入场动画停止，Canvas 鸟群只绘制静态首帧。

## 5. 本轮发现并修复的问题

| 问题 | 修复 |
| --- | --- |
| 鼠标斥力方向写反，鸟会被指针吸引 | 改为 `bird - mouse` 的远离向量；增加靠近指针时的确定性方向回退与 46px 安全圈，避免鸟在指针中心形成微小轨道 |
| 个人介绍概览显示“0 篇笔记” | 页面补充加载 `notes-data.js`，使 Mock 概览能统计 24 篇笔记 |

| 下载链接缺少可访问名称 | 增加 `aria-label="下载 文件名（真实文件名）"` |

## 6. 已知限制

- 所有数据均为演示数据，文章、奖项、图集名称与比赛成绩为虚构示例。
- URL 按钮指向外部参考站点，不保证离线可用；页面主体不依赖外部资源。
- 没有真实后端、登录、上传或后台编辑器；接口契约见 `08-backend-api.md`。
- 文章正文当前为本地可信 HTML，不能直接接受未清洗的用户输入。
- 图库插图为手绘风格 SVG，不是真实照片；替换真实图片时只需改数据中的 `cover` / `photos[].src`。
- 目标为现代常青浏览器；使用了 `backdrop-filter`、`color-mix`、`text-wrap: balance`、`100svh` 等现代 CSS，极旧浏览器会有降级差异。
- 浏览器截图、CDP 脚本位于本地 `.qa/`，已在 `.gitignore` 中排除，不属于站点运行时。
