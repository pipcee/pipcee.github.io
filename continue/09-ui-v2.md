## 2. 设计决策

- **奖项列表**：沿用原有圆角矩形与色调胶囊，只把 `awards-grid` 从两列改为固定单列；桌面卡片占满 1180px 内容宽度，移动端为 343px，始终一列。
- **状态排版**：`目前状态` 与 `大二` 均为 12px；`大二` 使用系统字体、`font-weight: 700`，不再使用 21px 衬线大字，避免状态胶囊内字号跳变。
- **头像**：`AR.png` 为 790 × 790 方图，仍放在 4:5 圆角框内，使用 `object-fit: cover` 居中裁切左右两侧；图片保持本地文件，无远程依赖。
- **页脚**：所有页面只保留「回到首页」，不再出现 Email / GitHub 超链接。
- **数据兼容**：`profile.handle`、`profile.now`、`profile.socials`、`profile.location`、`profile.email` 仍保留在 Mock 与内容协议中，前端只是不再渲染，避免破坏 `GET /api/profile` 的既有响应结构。

## 5. 追加修正：状态对齐、每页 15 篇、移除文章元信息

### 5.1 目前状态与「大二」水平对齐

- 原因：标签使用等宽字体、数值使用正文字体，即使字号与行高相同，两种字体的基线仍可能产生视觉错位。
- 修正：`.about-status__label` 改为继承正文字体，与 `.about-status__value` 统一 `font-size: 12px`、`line-height: 1.45`，数值保持 `font-weight: 700`。
- 结果：两者盒模型顶边/底边完全一致（实测差值 0），文本基线重合。

### 5.2 文章列表每页 15 篇

- `js/notes.js`：`pageSize` 从 `4` 改为 `15`。
- `js/api.js`：`getNotes()` 的 `pageSize` 默认值从 `4` 改为 `15`。
- `notes.html`：列表标题文案改为「按日期倒序 · 每页 15 篇」。
- 当前每个文件夹 6 篇笔记，因此单页即可显示全部笔记，分页控件自动隐藏；后续笔记超过 15 篇时会自动分页。

### 5.3 移除文章日期、阅读时长与标签

以下位置不再渲染文章的 `date`、`readingTime`、`tags`：

| 位置 | 处理 |
| --- | --- |
| `notes.html` 笔记列表行 | 移除日期、`min read` 与标签列表，仅保留序号、标题、摘要 |
| `note.html` 详情页头部 | 移除 `#note-meta` 整个元信息块 |
| `note.html` 顶部 kicker | 移除末尾日期，只保留文件夹英文名与 `Notes` |
| 相邻笔记卡片 | 移除日期与阅读时长 |
| `css/style.css` | 删除 `.note-row__meta`、`.note-row__tags`、`.note-meta*`、`.note-series__meta`、`.tag`、`.tag-list` 及对应移动端规则；相邻卡片取消固定最小高度 |

数据层仍保留 `date` / `readingTime` / `tags` 字段，仅停止渲染，`GET /api/notes/:id` 与笔记索引结构不变。

## 6. 已知限制与观察

- **既有数据加载问题（未在本轮修改）**：`js/api.js` 的 `loadContent()` 没有把加载结果写回 `store`，因此即使 `mode: "static"` 且 `content/` 请求成功，`data()` 仍会回退到 `js/data.js`。当前关于页显示的 6 个奖项来自 Mock，而 `content/awards.json` 实际只有 1 条。该问题不属于本轮 UI 改动，为避免突然改变页面数据内容，本轮未修复。
- `assets/AR.png` 约 1.1 MB，上线前建议压缩或输出 WebP/AVIF 并提供响应式尺寸。
- 方图在 4:5 框内会裁切左右两侧；若需要完整展示，可后续把 `.about-portrait__frame` 调整为 `aspect-ratio: 1 / 1`。
